# Grandview OS – audit, October 2026

Read-only audit of commit `6142cf8` (22 Oct 2026), done before any further changes at the owner's
request. Six reviews ran in parallel: sales, estimating and proposals, production through completion,
security, code health and testing, screens and navigation. The owner-facing version, with the workflow
map, roadmap drawing and questions, is the Claude Doc "Grandview OS – Audit and Roadmap (October 2026)".
This file is the developer reference: every finding has an ID used by `docs/ROADMAP.md`.

Severity: H high · M medium · L low. Size: S ≤ 1 day · M 2–4 days · L 1–2 weeks.

## Summary

- Built in three days (20–22 Oct 2026, 37 commits) straight onto `main`, which deploys to production
  with migrations and no automated test gate. Typecheck clean; 714 unit tests pass; e2e passes locally.
- Strong: server-side permission checks on every action, crew views built from allow-lists with tests,
  mandatory two-step sign-in for office roles, no injection holes, careful uploads, encrypted tokens.
- Weak: release process; recovery from lockout; hand-offs between screens (estimate ↔ lead, colours ↔
  work order, status ↔ bookings); everything after "Complete" (invoicing, payments, costing, reviews,
  warranty) is missing; one job is spread over four pages with four numbers.
